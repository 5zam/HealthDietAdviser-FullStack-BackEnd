#  🥗 Health Diet Adviser

### 📌 Description
#### Health Diet Adviser is Full-stack single-page Web application using Angular & Java Spring Boot. It’s designed for those battling chronic diseases. Our core mission is to deliver evidence-based dietary recommendations, ensuring users are aligned with meals beneficial for their health.Whether you're managing a chronic condition or striving for a healthier lifestyle, Health Diet Adviser can guide you towards making informed dietary choices.

## Features

- **Admin Panel**: Administrators can log in with their credentials and have the "admin" role. They can manage chronic diseases and associated meals.

- **User Dashboard**: Users have the ability to log in with their credentials or sign up if they are new to the system. Once logged in, users can:
  - Create and manage multiple diet prescriptions.
  - Each diet prescription can include up to three meals.
  - View and modify their diet prescriptions.

- **Chronic Diseases**: Represents various chronic diseases that can be associated with specific meals.

- **Meals**: Represents individual meals that can be linked to chronic diseases.

- **Diet Prescriptions**: Users can create and manage diet prescriptions, each with a unique name, associated user, and a list of selected meals.

- **User Roles**: Defines user roles, differentiating between "admin" and "user" for access control.
