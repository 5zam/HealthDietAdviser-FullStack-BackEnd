#  🥗 Health Diet Adviser

### 📌 Description
#### Health Diet Adviser is Full-stack single-page Web application using Angular & Java Spring Boot. It’s designed for those battling chronic diseases. Our core mission is to deliver evidence-based dietary recommendations, ensuring users are aligned with meals beneficial for their health.
